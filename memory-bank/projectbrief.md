## Fő Szolgáltatások
1. **Takarmánykiegészítők** - SELENE, PANTOSAL NEW, METAFISIOL, AQUACID, ANPRO AMINOVIT, ANPROSOL AMINOPAN, ACESOL PLUS
2. **Szarvasmarha Füljelölők** - NÉBIH ENAR rendszerben gyártóként
3. **Gyógyszeradagolók** - Cambridge Agricultural Select Doser és Spinstir
4. **Szalmonella-mentesítési Program**

## Technikai Követelmények
- Tailwind CSS framework
- Reszponzív design
- SEO optimalizáció minden oldalon
- Biztonsági meta tagek
- Közös header és footer komponensek
- Debug console logolás minden JavaScript funkcióhoz
- Verzió számozás (v1.0.0)

## Design Irányelvek
- Világoskék színséma (#0066B3, #00A0E3)
- Modern, letisztult megjelenés
- Professzionális üzleti arculat
